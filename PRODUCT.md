# PluginRack — Product Context

**What it is:** A Windows desktop audio mixer that takes many inputs (hardware, system loopback, virtual endpoints), lets the user insert their own VST3 plugins on each input, and routes each channel to any combination of physical and virtual outputs. A Voicemeeter-class router with user-supplied effects instead of built-in ones.

**Who it's for:** Streamers, podcasters, and musicians routing microphones, game audio, and music into a single mix for OBS, Discord, or a DAW.

**Core job:** See every input at a glance, shape it with VST plugins, set levels, and route it — fast, during a live session.

**Surface mode:** Operate. The user is mid-task; familiarity, density, and scanability beat expression.

**Platform:** Windows 10/11 x64, JUCE native app.

**Pinned visual authority:** VoiceMeeter Potato. The user supplied a reference screenshot and asked for that console look, with the IntelliPan and Special FX sections replaced by VST plugin slots.

**Non-negotiables:**
- Dense professional audio-console layout: channel strips side by side, master/output section on the right.
- Dark blue-grey console surface, green faders, red mute, amber highlights.
- Every channel: source, VST insert rack, level, pan, mute/solo, output routing buttons, meter.
- VST rack replaces IntelliPan and Special FX.
